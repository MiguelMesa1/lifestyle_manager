# Lifestyle Manager

Aplicación web desarrollada con Django para gestionar hábitos y aspectos personales del día a día.

## Funcionalidades previstas

- Gestión de hábitos
- Registro de cumplimiento diario
- Autenticación de usuarios
- Dashboard principal
- Seguimiento del progreso

## Tecnologías

- Python
- Django
- SQLite
- HTML / CSS
